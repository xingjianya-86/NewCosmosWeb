# 异地协助功能（2026-11-27）

## 概述

异地协助是低收入人口认定流程的轻流程分支，仅做 **基本信息 + 入户调查 + 邻里走访文书**，不走分类认定/归档，不进入月报/首页统计/工作流。

## 数据模型

### nc_biz_applications 新增列

| 列名 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `application_type` | VARCHAR(30) | 'LowIncome' | 业务类型：LowIncome=低收入认定 / RemoteAssistance=异地协助 |
| `remote_marker` | VARCHAR(32) | NULL | 异地协助标记：`HukouMovedOut`=原本地档案已停保，按「户籍迁出」处理 |

### 新增状态

| 状态码 | 显示 | 说明 |
|---|---|---|
| `RemoteAssistanceDraft` | 异地协助办理中 | 等价草稿语义，但不进普通草稿 Tab |
| `RemoteAssistanceCompleted` | 异地协助已办结 | 终态只读，永不进入月报/在保/停保口径 |

- Web: `src/NewCosmos.Server/Migrations/006_remote_assistance.sql`

## 业务规则

1. **仅限本地无在享档案人员（方案 A）**：新建时按身份证校验当前库——
   - 本地在享（`Approved`/`Completed`）→ 拒绝，提示走「保障对象动态管理」；
   - 本地存在其它未闭环状态（草稿/已提交/不予受理等）→ 拒绝；
   - 本地仅有已停保（`Stopped`）档案 → 允许，并自动写入 `remote_marker='HukouMovedOut'`（标记「户籍迁出」）；
   - 本地无档案但历史导入库（6 库）存在该人 → 拒绝，提示先建档；
   - 本地与导入库均无 → 允许。
2. **同类型可多条**：通过校验后仍允许同一人多条异地协助记录（不影响低收入认定去重）。
3. **不走分类认定**：`ClassifyAsync` 拒绝异地协助。
4. **不走正式归档**：`CompleteArchiveAsync` 拒绝异地协助。
5. **办结后只读**：`IsEditable` 仅允许 `Draft` 和 `RemoteAssistanceDraft`。
6. **不进统计**：月报、首页、模块统计、工作流、档案查询均排除 `application_type='RemoteAssistance'`。
7. **邻里走访不落库**：仅打印《邻里访问调查表》文书，不新增走访记录表。

## 文书输出

- 《入户调查表》：doc_type=`入户调查`（模板 159）
- 《邻里访问调查表》：doc_type=`邻里访问`（模板 162，迁移脚本将原 `调查表` 调整为 `邻里访问`）

调查走访情况字段 `SURVEY_VISIT_SITUATION` 按入户调查结论生成：
> 经入户调查和邻里走访，该家庭情况{结论}。

## 验证清单

1. 执行迁移，确认 `application_type`、`remote_marker` 列和索引存在。
2. Web 新增异地协助，保存基本信息 + 入户调查。
3. 确认记录不出现在业务申请工作流、首页统计、月报表、档案查询。
4. 出《入户调查表》《邻里访问调查表》预览/打印。
5. 办结后状态为"异地协助已办结"，不可再编辑。
6. 桌面端新增/编辑同一条记录，验证两端共享。
7. 本地在享人员新建异地协助 → 被拒绝并提示走动态管理。
8. 本地已停保人员新建异地协助 → 允许，列表/表单显示「户籍迁出」标记。
9. 仅历史导入库存在的人员新建异地协助 → 被拒绝并提示先建档。
