# 低收入人口认定表单五步逐项对比（2026-11-25）

> 对照基准：`legacy/NewCosmos.Desktop` 桌面端 XAML / ViewModel。
> 当前实现：`web/src/views/applications/ApplicationFormView.vue` + `form/Step1-5`。
> 结论只描述差异与修法，不含代码改动。所有修复优先复用既有表/列，不新增数据库列。

## 0. 总结

五步不是“样式没对齐”，而是多层偏差：

1. **结构偏差**：Step1/3/4/5 都有旧版没有的卡片，也有旧版有但 Web 缺失的卡片。
2. **业务链路偏差**：赡养费公式与收入汇总、土地确权与土地收入、渐退期落库、提交语义都与旧版不同。
3. **字段偏差**：地址级联、疾病/重残、赡养人全量信息、能力鉴定、特困供养大量缺失。
4. **自创字段**：成员“单人保/自理能力”、Step1“申请原因/备注”、Step4“被调查人/关系”、Step5“赡养人/银行信息”等旧版没有或位置不对。

## 1. Step1 基本信息

### 旧版结构

1. 顶部红条：账号未绑定区划时禁止录地址。
2. 申请日期卡：只读日期 + “修改”，改期影响编号、公示窗口、卷号、文书、批次。
3. 户籍所在地：省只读；市/县/镇/村 Picker 级联；按账号管辖范围锁定；**无详细地址输入**。
4. 申请人所在地址（家庭住址）：省/市/县/镇/村 Picker + 详细地址；全国可选，默认账号机构区划。
5. 申请人信息：姓名、身份证（查库/照片）、残疾证号后两位、性别/年龄只读、联系方式、民族、婚姻、户口性质、文化程度、政治面貌、开户行、银行卡号。
6. 健康与残疾：身体状况/残疾类型/残疾等级只读派生；是否重病勾选；ICD-10 编码；一级/二级疾病；AI 建议；前 12 个月医疗自付。
7. **没有申请原因、原因说明、备注**（申请原因在 Step4）。

## 6. 横向共性问题

1. **只读/锁定**：旧版按状态/模式整步禁用（Step1-3 明确），Web 多数只在页脚隐藏按钮。
2. **字典/枚举**：前端硬编码选项，后端 key ↔ 中文映射不完整；关系、就业、健康、民族仍有英文回显或非法值落库。
3. **地址**：申请级、成员级都缺级联；旧版是 Picker + 锁定，Web 是自由文本。
4. **疾病/重残**：ICD-10、一级/二级疾病、是否重病、医疗自付判定是分类判定的输入，Web 基本没接。
   - **AI 建议（重病判定）已于 2026-11-27 完成接线**：病种目录 + 费用口径双通道、`ShouldAutoCheck` 闸门、只勾不取消、人工否决即停，见 `docs/20261127_AI重病判定Web接线.md`。上一句其余字段仍按原状处理。
5. **金额口径**：赡养费、土地收入没有按 Core 口径进汇总；渐退金额写错表。
6. **自创字段**：单人保/自理能力（无列）、Step1 申请原因/备注、Step4 被调查人/关系、Step5 赡养人/银行信息。
7. **提交语义**：旧版“提交”是保存并进入档案制作，Web 直接归档。

## 7. 建议修复批次

### 批次 A：先把结构改回旧版（不改业务链路）

1. Step4 恢复 3 卡；调查结论回第三卡；删除被调查人/关系；回访区移出 Step4。
2. Step1 删除“其他信息”卡和户籍详细地址；补申请日期卡。
3. Step5 删除赡养人/银行信息两张自创卡；恢复 6 卡骨架。
4. 全表单补只读模式（查看/复核/非草稿禁用）。

### 批次 B：修金额与数据链路（P0）

1. Step2 赡养费改为“月费可编、年费只读”，按 `月 × 月数 × 家庭人口` 计算，并汇总进 `alimony_income`；无赡养能力跳过。
2. Step3 土地确权组完整编辑；土地导入写确权组；土地收入由确权组计算。
3. Step5 渐退改用 `nc_biz_grace_periods`，判定时写入、GET 时读取；补确认与封顶。

### 批次 C：补字段与联动

1. Step1/Step2 地址级联（申请级 + 成员级）。
2. Step1/Step2 疾病：是否重病、ICD-10、一级/二级、医疗自付判定。（**其中 AI 建议/重病判定已 2026-11-27 完成**，见 `docs/20261127_AI重病判定Web接线.md`）

4. Step5 特困供养方式/机构/照料人参与判定；能力鉴定六项。

### 批次 D：补缺失功能

1. 一事一议（入口 + 页面 + 端点 + Core 服务）。
2. 单人保提示与创建草稿。

4. 回访记录恢复到表单页顶部。

1. 关系/就业/健康/民族等选项与后端 key 对齐。
